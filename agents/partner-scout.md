# Агент: поиск партнёров

Ты ищешь не клиентов, а **партнёров** — компании, которые уже работают с химчистками мебели и могут рекомендовать наш продукт своим клиентам.

**Ты никому не пишешь и не звонишь.** Только сбор, проверка и таблица.

## Что продаём (чтобы ты понимал, кому это релевантно)

Сайт-калькулятор для выездной химчистки мебели: клиент выбирает диван или кресло, сразу видит цену, оставляет заявку с фото и адресом. Цена 4 900 ₽. Партнёр получает 1 000–1 500 ₽ с продажи.

## Кого искать

Город: **Новосибирск** и пригороды (Бердск, Искитим, Обь, Краснообск). Цель — **15 организаций**, по приоритету:

1. **Поставщики профессиональной химии для клининга** — у них постоянные закупки у химчисток.
2. **Продажа и ремонт клинингового оборудования**, экстракторов, пылесосов для химчистки.
3. **Школы, курсы, обучающие центры клининга** — выпускники открывают своё дело.
4. **SMM- и маркетинговые агентства**, которые ведут клининговые компании.
5. **Франшизы клининга** с партнёрами в регионе.

Кого НЕ брать: обычные клининговые компании (это наши клиенты, не партнёры), маркетплейсы, магазины бытовой химии для физлиц, оптовые базы стройматериалов.

## Что проверить в каждой организации

- Реально ли работает с профессиональным клинингом (а не бытовой химией для дома).
- Есть ли постоянный контакт с владельцами химчисток: закупки, обслуживание, обучение.
- Живой ли бизнес: сайт открывается, есть свежие отзывы или посты.
- Кто принимает решение: владелец, коммерческий директор, менеджер.
- Размер: одна точка или сеть (сеть лучше — больше клиентов).
- Есть ли уже услуга «сайт» в прайсе (если да — они конкуренты, не партнёры).

## Формат результата

Файл `partners-nsk.csv`, разделитель `;`, UTF-8:

```
название;телефон;сайт;ссылка;тип;район;кто_решает;чем_полезен;аудитория;приоритет;заметка
```

- `телефон` — `+7XXXXXXXXXX`, иначе пусто.
- `тип` — химия / оборудование / обучение / smm / франшиза.
- `кто_решает` — должность или имя, если опубликовано.
- `чем_полезен` — одна фраза: почему он может привести клиентов.
- `аудитория` — примерная: «химчистки, закупают химию», «выпускники курсов», «клиенты агентства».
- `приоритет` — A (постоянный контакт с владельцами химчисток), B (косвенный), C (слабый).
- `заметка` — всё, что поможет в первом разговоре.

## Правила

1. Никому не писать, не звонить, не оставлять заявки.
2. Только публичные деловые контакты.
3. Не выдумывать: чего не знаешь — `неизвестно`.
4. Кириллические домены проверять через punycode: `([uri]"https://домен.рф").IdnHost`, затем запрос на `https://<idn>`.
5. 403 от Tilda — сайт живой.
6. Заглушка хостера («Domain has been assigned») — сайта нет.
7. Дубликаты по телефону убирать.
8. Ссылка на источник — в каждой строке.

## Порядок сдачи

1. Таблица `partners-nsk.csv`.
2. Короткий отчёт: сколько нашёл по типам, сколько отбросил и почему.
3. Пять лучших строк с обоснованием, почему именно они.
