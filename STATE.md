# Состояние проекта «Мягко»

Обновлено: 23.11.2026. Этот файл — точка входа для новых сессий. Читать первым.

## Что это

Шаблон сайта для выездной химчистки мебели, который продаётся компаниям как готовый продукт с адаптацией.

Клиент: открывает ссылку, выбирает мебель, видит предварительную цену, оставляет заявку с фото и адресом. Владелец: получает заявку в кабинете и в Telegram, согласует цену и время, клиент видит изменения по приватной ссылке.

Цена продукта: 4 900 ₽ (адаптация + первый месяц сервера). Дальше сервер ~500 ₽/мес платит владелец.

## Решения и почему

- **Один экземпляр = одна компания, отдельная база.** Требование шаблона: клиенты не должны видеть чужие заявки.
- **Сервер в РФ, не Vercel, для платных клиентов.** `*.vercel.app` в России не открывается без VPN; Vercel Hobby запрещает коммерческое использование.
- **Демо живёт на Vercel.** Бесплатно, автодеплой, для показа годится с оговоркой про VPN.
- **Фото — одна штука на позицию плюс «до».** Не альбомы и не видео: сложность не оправдана.
- **Уведомления только в Telegram.** SMS платные, почту не читают, push на iPhone ненадёжен.
- **Универсализация расчёта вместо новых ниш через код.** Иначе каждая продажа = разработка.
- **Цена 4 900 для клининга, 9 900 для других ниш.** Вторая ниша требует адаптации полей.
- **Никаких обещаний онлайн-записи, оплаты на сайте, CRM, SMS.** Этого нет в продукте.

## Что пробовали и не сработало

- **Холодные звонки** — 12 попыток, 0 интереса. Мастера с 2ГИС не видят проблемы, новички не готовы платить.
- **Холодные сообщения в WhatsApp и Telegram** — доставлено, не прочитано. Ссылка в первом сообщении повышает риск ограничений.
- **Скрипт «интересно ли вам»** — мгновенный отказ. Работает только вопрос про его процесс («как клиент узнаёт цену?»).
- **Заход через сломанный сайт** — разговор начинается, но на предложении обрывается.
- **Доверять таблице сборщика без проверки** — четыре ошибки: «нет сайта» там, где сайт есть (ЧистоБудет, Русский Блеск, Стандарт чистоты, Делаем чисто). Теперь каждый сайт проверяется запросом.

## Правила достоверности (обязательны для всех агентов)

1. **Не выдумывать.** Нет данных — писать «не проверено» или «неизвестно». Догадка, выданная за факт, хуже отсутствия ответа.
2. **Проверять перед утверждением.** Фраза «у вас нет сайта», «нет цены», «домен мёртв» допускается только после запроса: `curl -k -s -o NUL -w "%{http_code}" -A "Mozilla/5.0" <url>`. Кириллицу — через punycode. 403 от Tilda — сайт живой. 502/504 перепроверять дважды.
3. **Ссылка на источник.** Любое утверждение о клиенте — с URL страницы, где это видно.
4. **Не придумывать цифры.** Отзывы, цены, конверсии, сроки — только из проверенного источника. Оценки помечать как оценку.
5. **Не обещать того, чего нет в продукте.** Онлайн-запись по слотам, оплата на сайте, кабинет для клиента, CRM, SMS, мобильное приложение — этого нет.
6. **Не отчитываться о непроверенном.** «Тесты прошли» — только с выводом команд. «Проверил на телефоне» — только если проверено.
7. **Не выдумывать API, версии и флаги.** Проверять в официальной документации или в исходниках проекта.
8. **Отделять факт от предположения.** «Вижу X», «предполагаю Y», «не проверял Z» — разными словами.
9. **Спорное — спрашивать.** Не угадывать требования, не менять объём задачи молча.
10. **Секреты не публиковать.** Токены, пароли, ключи — только в `.env` и переменных окружения, не в чат, не в репозиторий.
